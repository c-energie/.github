# Getting help

- **Documentation:** start with the umbrella docs at <https://c-energie.github.io/bea-docs/>.
  They hold the tutorials, the how-to guides for cohort adapters and model packages, and the
  explanation of the contracts and vocabulary.
- **A bug, a feature request, or a question about writing a cohort adapter or model package:**
  open an issue in the repository concerned and choose the matching issue form. Blank issues are
  switched off, so that every report carries the details needed to act on it.

Contributing a change is covered in [`CONTRIBUTING.md`](https://github.com/c-energie/.github/blob/main/CONTRIBUTING.md)
(or the repository's own, where it has one).
